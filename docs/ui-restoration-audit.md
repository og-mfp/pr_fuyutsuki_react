## Restoration decision

Preserve the compatible Laravel shell, Inertia resolver, auth layouts, Wayfinder actions, theme state and RBAC navigation. The reference UI uses older asChild APIs and custom context primitives; copying these over Bits UI would undo keyboard/focus support. Use one current official nova component foundation instead, preserving Laravel's default theme and layout structure.

Restore custom Button, Alert, Input, InputGroup, Calendar and Dialog changes from the official CLI snapshot. Keep reviewed Bits UI 2 attribute-selector corrections, the sidebar active-attribute correction, and TypeScript-only fixes. Move DataTable outside ui; retain all existing controls and callers. Replace dialog static with supported dismissal props. Add compatible registry categories; omit Form because it requires SvelteKit Superforms.

Scope: components/ui, application shell and affected consumers, ui pages, explicit route manifest, admin navigation, catalog tests and frontend documentation. No database or business-controller changes.
